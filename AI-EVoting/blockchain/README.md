# Blockchain (Hardhat)

This folder contains the Hardhat project for the Voting smart contract.

Commands:

Install dependencies:

```bash
npm install
```

Compile:

```bash
npx hardhat compile
```

Start local node:

```bash
npx hardhat node
```

Deploy to local node (in another terminal):

```bash
npx hardhat run scripts/deploy.js --network localhost
```
