# AI-Powered Secure E-Voting System

Scaffolded project for the AI-powered secure e-voting system.

Folders created:

- `frontend/` - React (Vite) app skeleton
- `backend/` - Node.js + Express app skeleton
- `blockchain/` - Smart contract placeholders
- `ai/` - AI fraud detection pipeline placeholders
- `database/` - Database notes and migration placeholders
- `docs/` - Documentation
